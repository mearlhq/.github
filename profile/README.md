# Mearl

[简体中文](#mearl) | [English](#english)

在自己的浏览器里，和 Agent 一起操作与调试网页。Mearl 沿用浏览器的登录态，帮你验收功能、排查请求问题、核对设计稿或导出报表。验证过的任务可以封装成 Skill，供 Agent 重复使用。

[官网与快速上手](https://mearlhq.github.io/mearl/) · [主仓库](https://github.com/mearlhq/mearl) · [扩展下载](https://github.com/mearlhq/mearl/releases)

### 给 Agent 安装 Mearl Skill

```bash
npx --yes skills add mearlhq/mearl --skill mearl --global
```

安装后，让 Agent 按 Skill 的指引配置本机环境并验证浏览器连接。[安装说明](https://github.com/mearlhq/mearl#开始使用)

## English

Automate and debug web pages with an agent in the browser you already use. Mearl reuses your browser's sign-in to help you test features, troubleshoot requests, compare designs, or export reports. Package verified tasks as Skills your agent can run again.

[Website and quick start](https://mearlhq.github.io/mearl/en.html) · [Main repository](https://github.com/mearlhq/mearl) · [Extension downloads](https://github.com/mearlhq/mearl/releases)

### Install the Mearl Skill for your agent

```bash
npx --yes skills add mearlhq/mearl --skill mearl --global
```

Then ask your agent to follow the Skill's instructions to set up your local environment and verify the browser connection. [Installation guide](https://github.com/mearlhq/mearl/blob/main/README.en.md#get-started)
